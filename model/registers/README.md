# registers

What spans every level, so it cannot live in one compartment.

| File | Holds |
|---|---|
| `design_decisions.csv` | what the system is |
| `method_decisions.csv` | how the model is written |
| `open_questions.csv` | questions that are held, not guessed at |
| `compartments.csv` | the code and directory of each compartment |

Risks are not here. A risk belongs to the compartment whose failure it describes.
