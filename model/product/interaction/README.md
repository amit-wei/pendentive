# Interaction (`IA`)

Carries every exchange between the system and the person, by speech and by text.

From `FUN-PL-06`. It sends what `FUN-PL-13` raises to the user. Six of the eight
product obligations that span systems pass through it.

`AU` sent four questions here. `OPN-049`: which system receives the answer of the
user, which `REQ-PL-030` states the platform records as it received it. `OPN-051`:
what a caller does when `AU` gives no answer at all. `OPN-052`: what tells the user
that a declared class was removed. `OPN-003` has waited since session 1.

The functions and requirements of this system are not yet written.
