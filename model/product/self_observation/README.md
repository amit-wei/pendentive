# Self-Observation (`SO`)

Holds and reports the cost and the operational state of the system.

From `FUN-PL-11`. Its body of data is separate from life state (`DEC-006`). `DEC-106` puts the record of
each act on the outside world here, with the authority by reference, and Actuation
reads it back (`INT-PL-43`, `INT-PL-49`, `OPN-082`).

The functions and requirements of this system are not yet written.
