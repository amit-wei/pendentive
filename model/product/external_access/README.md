# External Access (`EX`)

The only route from the platform to an external service. Holds the register of
external services and their credentials, carries calls to them, and records each
call that it made.

From `FUN-PL-02` and `FUN-PL-08`. It carries. It does not decide. `AC` decides what
is a change, and `AU` gates it.

The functions and requirements of this system are not yet written.
